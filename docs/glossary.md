# Słowniczek

- **SnapshotID** — identyfikator wersji danych źródłowych z ekstraktu POS.
- **LoadId** — identyfikator uruchomienia procesu ładowania danych, powiązany z
  `dbo.LoadLog`.
- **Tier** — poziom klienta: Bronze, Silver, Gold.
- **SubItemNo** — numer pozycji podrzędnej w ramach linii zamówienia.
- **GrossAmount** — kwota po rabacie, przed VAT.
- **VatRate** — stawka VAT przypisana do produktu w momencie sprzedaży.
