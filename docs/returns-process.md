# Proces zwrotów i korekt zamówień

Zwroty klienckie (uszkodzony towar, pomyłka w wysyłce) są rejestrowane w systemie
zwrotów w dniu zgłoszenia przez klienta.

Dodatkowo: jeśli zamówienie zostanie anulowane już po tym, jak towar został
wysłany/zrealizowany, dział finansowy księguje korektę w kolejnym miesiącu
rozliczeniowym jako wpis w systemie zwrotów z powodem `ORDER_ADJUSTMENT`. Nie
jest to zwrot inicjowany przez klienta, tylko korekta księgowa.
